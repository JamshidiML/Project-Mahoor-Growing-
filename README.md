# Project Mahoor — Growing Together

این مخزن خصوصی برای مدیریت عملیاتی رشد خانوادگی، رابطه والد–کودک و حمایت از رشد سالم ماهور ایجاد شده است.

> موضوع پروژه «بهینه‌سازی یا رتبه‌بندی کودک» نیست؛ موضوع پروژه، کیفیت حضور والدین، فرصت‌های رشد، امنیت روانی، استقلال متناسب با سن و بازبینی مستمر روش‌های والدگری است.

نسخه عملیاتی اولیه در شاخه `setup/operating-system-v1` توسعه داده می‌شود.
