# داده‌های ساختاریافته

این پوشه فقط برای داده‌های حداقلی و غیرشناسایی‌کننده استفاده می‌شود.

## مسیرها

- `weekly/YYYY-Www.json` — ورودی هفتگی استخراج‌شده از فرم یا گزارش صوتی
- گزارش‌های تولیدشده در `08-reports/weekly/`, `08-reports/monthly/` و `08-reports/yearly/` قرار می‌گیرند.

## جریان صوت تا گزارش

```text
یادداشت صوتی والد
    ↓
رونویسی و بازبینی انسانی
    ↓
استخراج طبق weekly_input.template.json
    ↓
ثبت فایل در 07-data/weekly/
    ↓
GitHub Action
    ↓
FOS + گزارش هفتگی + تجمیع ماهانه و سالانه
    ↓
تحلیل روایی دستیار و چرخه اصلاح
```

## نام‌گذاری

```text
07-data/weekly/2026-W32.json
07-data/weekly/2026-W33.json
```

## اطلاعات ممنوع

- فایل صوتی یا تصویر ماهور
- نام کامل کودکان دیگر
- نام و نشانی مدرسه
- آدرس خانه، شماره تماس یا اطلاعات شناسایی
- اسناد پزشکی یا تشخیص‌ها
- متن خصوصی گفت‌وگوهای ماهور
- ضبط مخفیانه همسر، کودک، معلم یا دیگران

## اصل نگهداری

در پایان هر ماه، شواهد متنی طولانی خلاصه و اطلاعات غیرضروری حذف شود. برای تحلیل روند، امتیازهای والدین، تصمیم‌ها و مشاهده‌های بی‌نام کافی است.
